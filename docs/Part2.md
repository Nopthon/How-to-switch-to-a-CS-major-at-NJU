# 二. 转专业考试的具体内容

以下包含了转专业考试的具体内容，**由于跨大类准入方案中只会告诉你有“笔试、机试、面试”，<u>连考试范围都不会告诉你</u>，所以下面的内容仅供参考**

!!! success "目前来说的好消息是"

    转计算机考试的形式和考试范围这几年一直没有什么变化，所以你可以以 90%+ 的置信度参考下面的内容

## 笔试

两个小时、四道数学题，可参考的考试范围是离散数学（图论、群论、集合论）、微积分（偏向数学分析风格）、线性代数（以矩阵性质为主）的内容，事实上考察比较灵活，比如近三年有两道题以图论为背景，但是实际只是套壳，考察的是其他知识点

笔试难度每年存在浮动，总的来说，群论和集合论的题目需要**扎实的离散数学基础**，而图论的题目一旦像 25 年那样出非套壳类题目则通常很难（否则一般有个“小巧思”就能做出来）；微积分题目难度中等，线代题通常是全卷最简单的，<del>写不出来心里会很难受</del>

??? warning "关于离散数学的考试范围，与《离散数学》课程的教学范围的不对等性"

    （从 26 年考试情况来看），群论在笔试的考察范围内，但是现有的 3 学分课程《离散数学》不包含，因此**这部分内容需要自学**
    
    （24 级及以前的 5 学分离散数学课程是包含的，现在课改把这门课拆分了）

???+ quote "近三年的实际考试范围"

    26 年笔试试题的四道题分别是 微积分 + 群论 + 图论（本质考察组合数学） + 线性代数
    
    25 年笔试试题的四道题分别是 群论 + 集合论 + 线性代数 + 图论
    
    24 年笔试试题的四道题分别是 群论 + 集合论 + 微积分 + 图论（本质考察线性代数）

你可能要问笔试的分数线是多少，我只能说能写的尽量写，假装老师会捞人，但是不要写太明显的伪证，因为伪证得 0 分，写放弃得 2 分，每道题 25 分

几门数学课好好学问题不会太大，并且笔试的分数线似乎很宽松

## 机试

三个小时、三道 OJ 题，形式可以参考 Luogu 的非 Div4 比赛设置

??? abstract "有关机试的琐碎细节/要求，这部分内容在你有一定的编程基础之后再看"

    **IOI 赛制**, 提交即出结果且可反复提交（你可以查一查 IOI 赛制是什么）
    
    试题通过试题册单独提供而不会在 OJ 上提供；每道题目按照测试点平均给分, 题型均为传统题, 内存上限均为 512MB
    
    使用与 CPL / 问题求解 课程相同的 OJ 环境（dotOJ），只允许用 C/C++ 提交（具体地说，**C++ 使用的版本是 C++17**, C 语言使用的版本是 C17；使用Python与Java的提交得分无效），每 15s 允许提交一次
    
    允许使用的 IDE 有: Embarcadero Dev-C++, Code::Blocks, VSCode（安装了必要插件的离线版）, VS (没有 Clion)
    
    可以用万能头 `bits/stdc++.h`，换行符用 `endl` `\n` 都可以（评测机是 Windows 环境）
    
    场上会有大屏幕实时展示匿名榜单，只展示用户名和分数（用户名和密码会以密码条的形式现场提供）
    
    !!! question "如果你担心上面的细节会有所改变的话"
    
        在笔试后有半小时试机时间, 可以熟悉编程环境（<del>以及不太好用的键盘</del>）；另外**以上所有内容都会下发 PDF 文件进行详细说明**，你可以在试机时了解

机试的难度每年存在较大浮动，因此也不好进行一个统一的评价

???+ quote "近三年的知识点考察情况，大致难度，分数分布情况"

    26 年机试试题的三道题分别是 (模拟) ~ (状压 DP / 枚举) ~ (图上博弈)
    
    - 难度大致为洛谷 绿-青-蓝，单题最高分 100pts ~ 100pts ~ 40pts
    - 及格线为 70pts / 300pts，对应 rk12（仅参考转专业成功的人中机试最低的分数，实际及格线可能更低）
    - 考场最高分 205pts；100pts 以上有 7 人（205-200-175-135-135-110-110）
    
    ---
    
    25 年机试试题的三道题分别是 (贪心) ~ (线性 DP + 前缀和优化) ~ (最短路)
    
    - 难度大致为洛谷 黄-绿-绿，因为有 AK 的所以单题最高分都是 100pts
    - 及格线为 170pts / 300pts，对应 rk12（仅参考转专业成功的人中机试最低的分数，实际及格线可能更低）
    - 考场最高分 300pts；200pts 以上有 5 人（300-220-200-200-200）
    
    ---
    
    24 年机试试题的三道题分别是 (贪心 + 树状数组优化) ~ (递归分治/树形 DP) ~ (计数 DP + 生成函数)
    
    - 难度大致为洛谷 绿-黄-青
    - 及格线不知道
    - 顺带一提，T1 不使用数据结构优化可以拿 90pts，因此它的得分难度小
    
    （如果你不知道洛谷搞了个额外的青题难度并将难度标准进行了更细的划分，就把它理解为中下等难度的蓝题）

这里从考试现场的角度大致说一下最近两年的考试情况：

!!! question "你可能会觉得下面的内容很流水账，但事实上这些信息大致可以还原真实的考场情况，还是有些帮助的"

- 26 年

26 年机试没有明显的签到题（相比前两年来说），监考官预测开考 40min 才会出现第一题的首杀（并且预测正确），相比之下，25 年的第一题开考 30min 就有一半人写出来

机试考场相较于你平时的练习，会有一定的压力（主要体现在：大屏幕实时投出排行榜，监考官（应该是出题人学长）很热情，会时不时地说话，并且会隔一会刷新一下排行榜，并通报每个题的一血，给你无形的压力）

整体难度对标 CSP-S T2-T3 的程度（主观）

三道题的 AK 情况为：第一题 4~5 人 AK，第二题仅 1 人 AK，出现在 90min，第三题无人 AK，最高分 40pts

考场上的 200pts 和 205pts 分别出现在 2h 和 2h50min 时，比较靠后

三道题的部分分情况是：第一题模拟有一半人可以得到 60pts 左右，打表大样例能过一个点；第二题状压 DP 部分分情况不佳（拿到的人很少）；第三题只判断路径可达性有 30pts 部分分

- 25 年

25 年机试有明显的 T1 签到题，开考 7min 左右出现首杀，笔者在 15min 写出，此时有约一半人写出，然而有 10 个人左右到考试结束都没有 Accepted 第一题

在这之后的两个小时，排行榜上后两题的进展都不大，多数人选择先做最短路改造的第三题，并且拿到 60pts 的部分分。裸 Floyd 可以拿 30pts，暴搜剪枝可以拿 40pts，有部分人拿到 30pts~80pts 部分分，因为测试点数据比较毒瘤（卡常），Accepted 人数只有一个

而第二题动态规划因为状态转移需要有巧妙的考虑（转换状态设计的思路），部分分非常惨淡，特殊样例的部分分能够拿到 30pts，出题的监考官在考试期间说“第二题应该比第三题简单”，并直接将第二题的时限从 1s 上调到了 3s 来鼓励暴力解拿部分分，事实上暴力解也不超过 40pts

2h45min 出现了全场唯一的 AK（完成题目的顺序是 1-3-2），在此之前排行榜上有四五个 200pts 左右分数

顺带一提，第二题打表大样例可以拿到 5pts，这两年都有大样例 = 测试点的题目

---

如果需要总结机试的准备技巧的话：

- **训练**。转计算机机试的难度远超大一开设的绝大多数课程的 OJ 题目难度（应该比问题求解高），对于有基础的 OIer 来说也需要进行一定的训练（复健？），对于零基础的萌新来说，至少需要抽出一整个学期的时间对算法相关进行强度较高的学习
    - 可以在 Codeforces、Luogu 等平台进行典型题目的训练，并且适当进行 Div-3/Div-2 比赛的报名（虚拟参赛）
    - 不考虑 AK 比赛而是通过机试，大概需要 Div3 做出 75% 的题目；想 AK 比赛的建议做到稳定 AK Luogu 的 Div3。考虑到今年难度变大，也可以试试 Div2
    - 笔者 Codeforces Rating 为 ~1400，提这个是因为我就是压线机试的水平 (＠_＠;)
    - **一定要理论结合实战，这玩意在拼能力的同时也是会吃心态的！**
- **骗分**。你会发现在考场上完全写出一道题不是容易的事情，但是有一些比较常用的手段可以帮助你获得部分的分数，我们统一称之为“骗分”：
    - 特殊测试点：这部分测试点有特殊性质，往往可以用更简单的算法实现，或者对思考出正解有引导作用
    - 暴力解 + 剪枝：测试点的规模是从小到大的，时间复杂度过大的算法对于小样例依旧有概率通过；通过剪枝进一步优化常数有期望得到更多的分（比如 25 年 T3 不剪枝纯暴力只能拿 0pts，剪枝后 40pts）
      - 更极端的，你可以设计一个不正确的、但是优化非常明显的剪枝，并且期望在比较多的测试点上恰好成立
    - 局部分类讨论：一个题目需要考虑很多种情况（或者设计出一个广泛算法很复杂），但是某些讨论情况可以提前输出一个显然的答案 / 设计出一个的更好想的算法（比如“对两个有序数组合并，如果第一个数组的最大元素小于第二个数组的最小元素，则直接首尾合并”这样的特殊情况讨论）
      - 特殊测试点的骗分是根据测试点给出的特殊性质构造特殊的解法；局部分类讨论是在无法覆盖整个讨论空间的情况下，最大化算法能够覆盖的讨论空间范围，并给出这部分讨论空间的正确算法（比如“边界情况”）
    - 打表：分两类，一类是离线预计算一个大数组之类的并直接粘贴到代码段，减少代码运算某些固定内容的开销；另一类是打表样例（这两年都可以骗分，何乐而不为）
    - 随机化：假设一个题目输出 True/False，而自己完全不会写这道题，那么就引入 `random` 大力出奇迹吧（这种题目一般会输入一个 `T` 进行单测试点多测阻止这种行为，但是想赢的人脸上是不会有笑容的，对吧）
      - 有实力的可以升级为最优化算法，比如写爬山、模拟退火（真的有人会这么做吗）
- 骗分手段不是独立的，<del>以及我真的花了一面内容去写怎么骗分，这辈子有了</del>

## 面试

**无需准备，自信面对即可**

转计算机面试不需要准备自我介绍 / PPT / 成绩单等各种东西，因为面试问的内容会非常随机，而且大多数问题都是专业课 / 学业规划相关。答不出考官问的问题非常正常，实事求是说自己不知道也是完全没有问题的。另外，考官应该不知道学生的 GPA 和选课情况（所以老师可能会顺便问一问）

面试几乎不卡人，只要不把考官惹火了 / 问啥啥不会以至于面试无法推进就不会有问题
